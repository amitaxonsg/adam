## Questionnaire

Open [index.html](./index.html) in a browser. It contains **123 detailed questions across 11 sections**, including company/domain/email details, garment editor, roster, manufacturing and print output, payments, suppliers/API, shipping/API/tracking, operations, hosting and acceptance.

### How Adam completes it
1. Open the hosted questionnaire if GitHub Pages is configured. Proposed address: https://amitaxonsg.github.io/adam/ (this URL works only after Pages deployment is enabled).
2. Type responses; unanswered questions can be left blank or marked **TBC**.
3. Click **Download responses (JSON)** and send the resulting file to the Axon project team through an agreed secure channel. Optionally use **Download readable answers** or **Print / Save PDF**.
4. To continue later, retain the JSON file and use **Import previous JSON**. The HTML questionnaire **does not automatically store or submit answers**.
5. Axon reviews submitted answers and records confirmed decisions, gaps, and approved changes in a version-controlled project specification. Do not upload confidential submissions publicly.

### Confidentiality
Never enter API tokens, passwords, private customer lists, payment credentials, secret keys, or other sensitive materials in this questionnaire. Supply service-provider name, official documentation links, contact, requested capabilities and API access prerequisites only. Any secrets must be exchanged through an approved secure process and kept outside Git.

### Enabling GitHub Pages
Repository → **Settings → Pages** → **Build and deployment** → **Deploy from a branch** → select **main** and **/(root)** → **Save**. Confirm the deployment succeeds before giving the proposed public URL to the customer. Note that a public Pages site is readable by anyone with the link, and the questionnaire does not provide private storage, automatic email submissions, or customer authentication.

## Discovery-to-blueprint workflow
- **Draft:** Adam submits answers and examples of existing production artwork.
- **Validate:** Joint walkthrough of one real order, sample factory/RIP export, and supplier/courier API availability.
- **Decide:** Document confirmed requirements, integrations, open questions, accepted exclusions, and MVP priorities.
- **Approve:** Client signs scope, acceptance tests, cost and milestones.
- **Build:** Only then begin implementation and production integrations.

## Important production acceptance questions
Obtain actual manufacturing files: panel patterns, color profiles, print dimensions/bleed, factory machinery/RIP, target vector/raster formats and at least one verified sample demonstrating that digital design can be printed without manual recreation. A downloadable mockup is **not** necessarily print-ready production artwork.
